# BotMaker — Android-приложение для создания Telegram-ботов

Регистрация, создание ботов, их настройка и запуск — всё внутри приложения, без сервера и без компьютера.

## Как это работает

1. **Регистрация / вход.** Аккаунт (имя, e-mail, пароль) хранится на телефоне в зашифрованном хранилище
   (`EncryptedSharedPreferences`). Пароль не хранится — только соль и PBKDF2-HMAC-SHA256 (120 000 итераций).
   После 5 неверных попыток вход блокируется на 30 секунд.
2. **Менеджер-бот (один раз).** Вы создаёте в @BotFather обычного бота и включаете в его настройках
   «Bot Management Mode», затем вставляете токен в приложение. Приложение проверяет его через `getMe`.
3. **Создание бота.** Заполняете имя, username (на «bot»), приветствие и автоответы. Приложение открывает
   ссылку `https://t.me/newbot/<менеджер>/<username>?name=…`.
4. **Подтверждение в Telegram.** Вы нажимаете «Создать» — этот шаг Telegram оставляет человеку.
5. **Дальше автоматически.** Фоновая служба получает update `managed_bot`, забирает токен
   (`getManagedBotToken`), задаёт боту описание и команды и запускает его. Бот появляется в списке со статусом «Работает».

Новый бот отвечает: на `/start` — приветствием, на сообщения с ключевыми словами — автоответом,
на `/help` — списком тем; если автоответов нет, повторяет сообщение.
Приветствие и автоответы можно менять на экране бота, бота можно остановить или убрать из приложения.

## Сборка

**GitHub Actions** (как у вашего прошлого проекта): положите содержимое архива в корень репозитория и сделайте push —
`.github/workflows/build.yml` соберёт `app-debug.apk` и выложит его как артефакт `BotMaker-APK`.

**Android Studio:** откройте папку проекта, дождитесь синхронизации, Run.

Версии те же, что у проекта Uchet: Gradle 8.7, AGP 8.5.2, Kotlin 2.0.21, Compose BOM 2024.02.01, minSdk 26, targetSdk 34.

## Ограничения (важно)

- **Регистрация локальная.** Аккаунт существует только на этом телефоне: восстановить пароль нельзя, при удалении
  приложения или очистке данных аккаунт и список ботов пропадают (сами боты в Telegram остаются у вас).
  Облачный аккаунт потребовал бы сервера.
- **Боты работают, пока работает приложение.** Ответы обеспечивает фоновая служба на телефоне (значок в шторке).
  Если телефон выключен, нет интернета или приложение остановлено принудительно — боты молчат.
  Отключите оптимизацию батареи для BotMaker (Настройки → Настройки батареи).
- **Подтверждение создания даёт человек** в Telegram — полностью без него бота создать нельзя.
- Токены ботов лежат в зашифрованном хранилище приложения; резервное копирование Android отключено.
- Проверить доступность username заранее нельзя (это умеет только Telegram) — занятость покажет сам Telegram по ссылке.
